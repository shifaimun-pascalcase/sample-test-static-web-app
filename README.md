# Tower Cloud Landing Page

A professional, responsive landing page for Tower Cloud - your cloud infrastructure partner.

## Files included:

- `index.html` - Main landing page with navigation, hero section, about, services, and contact
- `styles.css` - Complete CSS styling with modern design and responsive layout
- `script.js` - JavaScript for smooth scrolling and navbar effects
- `README.md` - This file

## Features

- **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- **Modern UI/UX** - Clean, professional design with smooth animations
- **Smooth Scrolling** - Navigation links smoothly scroll to sections
- **Interactive Elements** - Hover effects and button animations
- **Professional Branding** - Tower Cloud branding with gradient text effects
- **Contact Information** - Ready-to-use contact details

## Getting Started

1. Upload this folder to your static web app
2. The website will be live immediately
3. Customize the content, colors, or contact information as needed

## Customization

- **Colors**: Modify the CSS variables in `:root` section
- **Content**: Update text in the HTML file
- **Contact Info**: Change email and phone in the contact section
- **Services**: Add or modify service cards as needed

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
